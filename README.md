# examples
A repository with examples related to KubeSlice

## Current Examples   

[kind](https://github.com/kubeslice/examples/tree/master/kind) - A script that will configure multiple kind clusters and interconnect them with KubeSlice.   

[egs](https://github.com/kubeslice/examples/tree/master/egs) - Some helper scripts to demo EGS on a kind cluster.

[distributed-mongodb](https://github.com/kubeslice/examples/tree/master/distributed-mongodb) - Example for deploying distributed MongoDB across multiple clusters.

[distributed-cockroachdb](https://github.com/kubeslice/examples/tree/master/distributed-cockroachdb) - Example for deploying distributed CockroachDB across multiple clusters.
